# 🍌 BANANA SLIDES

**让演示，回归叙事。**

纯浏览器端 AI 演示文稿 / 信息图生成器 —— 粘贴素材，一次生成完整叙事幻灯片、逐页 AI 配图与小红书推广文案。

React 19 · Vite · Gemini API · 无后端 · 用户数据只存你的浏览器

</div>

---

## ✨ 它能做什么

| 能力 | 实际效果 |
|---|---|
| 📽️ **幻灯片模式** | 一段原始素材 → 5–15 页完整叙事演示文稿（含海报级封面、强收束封底），每页含叙事意图、内容、视觉描述、版式四要素 |
| 📊 **信息图模式** | 两阶段生成高密度竖屏信息图：先出 3–8 章节大纲，再逐章展开为卡片；专有名词输出「中文（English）」双语格式，适合移动端阅读 |
| 🎨 **逐页 AI 配图** | 每页独立生成 1K 高画质图像；5 种画幅比例（默认 3:4 小红书竖版）；17 种内置风格可整体套用或单页覆盖，随时换风格重新生成 |
| 📣 **小红书文案引擎** | 文稿生成后自动产出推广文案：≤20 字带 emoji 的吸睛标题、600–800 字结构化正文、恰好 5 个高热标签；支持「基于大纲」或「基于原文」两种方式重新生成，一键复制 |
| 🗂 **本地历史记录** | 所有项目（含已生成图片）持久化在浏览器 IndexedDB，侧边栏随时回看、删除；支持 JSON 导出备份与导入恢复 |
| 🔗 **链接导入** | 粘贴任意网页链接，经 r.jina.ai 自动转 Markdown 填入素材框，直接「读文章 → 出幻灯片」 |
| 📤 **多种导出** | 单页 PNG / 全部 PNG 批量下载 / Markdown 原稿（含全部叙事结构与提示词）/ 历史 JSON 备份 |
| 🔧 **全 Prompt 可定制** | 设置中心 6 个标签页可改：API 密钥、幻灯片核心指令、风格变量、推广 Prompt、画幅比例、信息图双阶段 Prompt —— 改 Prompt 即改产品行为 |

**技术栈**：React 19 + TypeScript + Vite 6，文本生成用 `gemini-3-pro-preview`，图像生成用 `gemini-3-pro-image-preview`。整个应用没有任何后端——你的 API 密钥、历史记录、生成的图片全部只存在你自己的浏览器里。

## 🚀 快速开始

### 获取并配置 API 密钥

1. 访问 [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key) 创建一个 Gemini API 密钥（需启用结算功能）
2. 打开 BananaSlides，**无需任何前置配置即可浏览全部界面**
3. 点击右上角 ⚙️ 设置 → 「API 密钥」标签页 → 粘贴密钥 → 点击 **测试密钥** 验证 → **保存配置**

未配置密钥时，输入页会显示一条温和的提示条；执行需要密钥的操作（生成文稿 / 生成图片 / 再生文案）也会弹窗引导你前往设置。

### 本地运行

```bash
npm install
npm run dev      # 开发服务器，端口 3000
npm run build    # 产出 dist/ 静态文件
```

`dist/` 是纯静态产物，可部署到任意静态托管（GitHub Pages / Vercel / Netlify 等）。

> 说明：`vite.config.ts` 中仍保留读取环境变量 `GEMINI_API_KEY` 注入 `process.env.API_KEY` 的构建期定义（AI Studio 模板遗留，运行时代码并不使用它，仓库中也没有 `.env.local` 文件）。**本应用实际使用的是设置中心里配置的密钥**，无需设置环境变量。

### 三步生成第一份文稿

1. **输入**：粘贴长文本素材 / 构思 / 大纲，或粘贴网页链接一键导入
2. **选模式并生成**：📽️ 幻灯片模式（叙事演示）或 📊 信息图模式（高密度卡片），点击「立即生成完整方案」
3. **配图与发布**：结果页逐页生成或批量生成图片（可任选风格）、单页换风格重生成；切到「营销文案」标签复制小红书文案直接发布

## 🧠 设计原理

这个项目的核心不是「调一次 API 出图」，而是一套**叙事优先（Narrative First）的分层生成架构**。

### 1. 每页四要素：叙事、内容、视觉、版式解耦

文本模型对每一页输出四个独立字段，而不是一段散文：

| 字段 | 作用 | 下游用途 |
|---|---|---|
| `narrativeGoal` | 该页在整体叙事弧光中的**战略意图**（为什么需要这一页） | 页面标题；营销文案的素材来源 |
| `keyContent` | 叙事主题句 + 高密度论据（数据 / 案例 / 逻辑） | 页面正文 |
| `visual` | 细致到主体、材质、光影、构图、色彩的可直接生图描述 | 独立图像生成 Prompt（卡片上可见、可复用） |
| `layout` | 构图层级（如「左三右七」、网格、对角线） | 图像生成的构图约束 |

**收益**：叙事逻辑、文字内容、图像、版式四层完全解耦——任何一页可以单独换 17 种风格中的任意一种重新生成图像，而不影响大纲与其他页面。

### 2. 结构化输出保证可靠性

所有文本生成均通过 `responseMimeType: application/json` + 严格 `responseSchema` 约束模型只输出合法 JSON（幻灯片路径还内置了一层括号匹配的 JSON 修复管线，兜底被 Markdown 代码块包裹或尾部拖带文字的输出）。每份文稿还附带模型自主撰写的 `styleInstruction`（全局风格基准），后续所有配图共享它以保持整册视觉一致。

### 3. 风格注入链

```
设置中的风格变量（17 选 1 或自定义）
   ↓ 注入
文稿生成 Prompt（影响模型写出的 styleInstruction）
   ↓ 传递
每页图像 Prompt（整体风格参考 + 该页 visual/layout + 画幅约束）
   ↓
gemini-3-pro-image-preview 逐页出图（串行队列，保持节奏稳定）
```

批量「一键生成图片」走严格串行队列逐张生成（右下角有排队指示器）；单页生成时可选择覆盖风格，所选风格会记录在该页上。

### 4. 信息图模式的两阶段策略

一次性让模型输出整册高密度信息图容易失控，因此拆成两步：**大纲阶段**（信息图架构师角色，规划 3–8 个章节与要点）→ **详情阶段**（信息图设计师角色，按「章标题 + 核心句 → 2–5 张纵向卡片 → 本章最关键一句」的竖屏模板展开，并从竖向流程图 / 卡片堆叠 / 时间线 / 指标卡 / 对照卡五种范式中选型）。产出的卡片复用与幻灯片相同的四要素结构，因此图片生成、历史记录、导出全链路共用。

### 5. 内置的反 AI 腔约束

Prompt 中显式禁止「不仅仅是…更是…」「在…的背景下」等 AI 套话；要求数据可溯源、禁止编造；封面/封底必须与内容页视觉差异化；标题须为可串成完整故事的叙事主题句。

## ⚙️ 设置中心详解

| 标签页 | 可配置项 | 说明 |
|---|---|---|
| API 密钥 | Gemini API Key | 支持显示/隐藏、复制、**测试密钥**；保存时自动去除首尾空格 |
| 核心指令 | 幻灯片生成系统 Prompt | 模板变量：`{userInput}` 素材、`{styling}` / `{styling_variables}` 风格、`{aspectRatio}` 画幅 |
| 风格变量 | 全局风格描述 | 17 个模板一键填充 + 自由编辑 |
| 推广配置 | 小红书文案 Prompt | 控制标题字数/emoji、正文结构与字数、标签数等策略 |
| 图片设置 | 画幅比例 | 1:1 / 3:4（小红书推荐）/ 4:3 / 9:16 / 16:9 |
| 信息图配置 | 大纲 / 详情两个 Prompt | 模板变量：`{userInput}`、`{title}`、`{styleInstruction}`、`{outline_chapters}` |

- 「恢复默认」会重置以上 Prompt 与比例，但**不会清除你的 API 密钥**
- 设置保存在浏览器 IndexedDB，修改后即时持久化

**🔒 密钥与隐私**：API 密钥仅以明文保存在本机浏览器的 IndexedDB（`BananaSlidesDB`）中。密钥只随请求直连 Google Gemini API，不会发送到其他任何服务器（本项目没有自己的服务器）；你的素材内容除链接导入时提交给 r.jina.ai 代理外也不会外发。页面运行时会从公共 CDN 加载静态资源（Tailwind CDN、Google Fonts、未生成图片页面的 Unsplash 风格预览图等），这些请求不携带密钥或你的内容。请勿在公用设备上保存密钥。

## ⚠️ 已知边界与限制

务实列出，避免误解：

- **导出形态**：产出为 PNG 图片与 Markdown 原稿，暂不直接导出 PPTX / PDF
- **生成等待**：无流式输出，整册文稿需完整等待；生成中的进度文案为轮播提示（信息图模式会显示真实的阶段里程碑）
- **批量生图**：严格逐张串行，暂无取消按钮；单张失败仅记录在控制台，可对该页重试
- **存储增长**：历史记录内联保存 base64 图片，长期使用体积会增长；可用导出 JSON + 删除记录管理空间
- **链接导入**：依赖第三方免费代理 r.jina.ai，可用性不受本项目控制
- **语言**：界面与生成内容以中文为主（信息图模式输出「中文（English）」双语格式）
- **费用**：使用你自己的 Gemini API 密钥，需启用结算；每份文稿 ≈ 1 次长文本生成（信息图模式为大纲 + 详情共 2 次）+ 1 次文案生成 + N 次图像生成（图像按 1K 画质计费），批量出图前请留意用量
- **密钥测试的边界**：「测试密钥」验证密钥本身有效性，不能保证该账号对 preview 模型的访问权限
